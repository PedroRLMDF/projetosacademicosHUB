# LimpeJá — Plataforma de Faxina a Domicílio

**Status:** Projeto em desenvolvimento

---

## Sobre o Projeto

O LimpeJá é uma plataforma web que conecta clientes a diaristas de confiança de forma simples, segura e sem complicação.

A ideia surgiu da necessidade de facilitar a contratação de serviços de limpeza residencial, eliminando intermediários e tornando o processo mais transparente para o cliente e para a diarista.

---

## Funcionalidades Planejadas

- Cadastro de clientes e diaristas
- Agendamento de serviços por data e horário
- Sistema de avaliações e comentários
- Pagamento online integrado
- Localização de diaristas próximas
- Painel do cliente e painel da diarista
